# MOVE 个人训练站设计

## 目标与授权
用舒适、简约、流畅的真实界面替换 rehab-training 及旧训练数据。用户先要求 Astra 设计，之后明确要求现在制作；按当前直接制作指令实施，不重复图稿审批。保留根目录简历、PDF、个人页面。基线 main 7463e956261d9ab132a149e31a7feb7fc378f630，任务分支 codex/personal-training-redesign。

## 视觉与交互
暖纸白 #F7F6F2，苔绿 #52634B，正文 #30372F，浅绿 #E8EDE3。桌面 176px 侧栏与宽松内容区，手机底部四项导航。首页：标题、日期、七日选择、舒缓训练主块与小幅窗光摄影、本周安排、开放动作列表。摄影是生成氛围资产，不是标准动作示范。减少全屏摄影、卡片叠套和粗重标题。系统中文字体避免外部字体阻塞；160–220ms 透明度/位移动效，尊重减少动态效果偏好。点击区域至少44px。

## 完整页面
今日：真实本地日期、选日安排、训练入口、主动休息；未来日期仅看计划。计划：本周及三个阶段、显式进阶条件。动作：分类搜索、真实来源视频与原站链接、每项步骤/错误/剂量。记录：日历、实际逐组记录、完成/部分完成/主动休息/因不适停止、训练后与次日反馈。设置：加练日、休息秒数、常亮偏好、阶段选择、导入导出与范围明确的清空。

## 训练内容
每日轻柔颈转每侧5次1组、仰卧小幅点头5次1组（保持3秒休息5秒）、步行10–15分钟。周一三六加练徒手向上够6次1组、徒手深蹲8次2组、扶墙提踵10次2组。组间默认60秒，可选45/60/90。先舒适活动，再两次稳定训练及次日反应后手动增量。阶段2向上够8次1组，不自动升级或假设已恢复。阶段3仅满足条件后每周2次低负荷划船，不推荐直接恢复侧平举、过顶或杠铃动作。无器械动作优先；哑铃实际重量由使用者填写，不预设杆重。

状态检查不作诊断。疼痛明显时只建议舒适走动与换姿势；出现麻木、无力、刺痛、痛性卡住停止。长期明显疼痛建议现场评估，不宣称视频能确诊翼状肩胛或保证自行治愈。当前方案为保守试行，评分门槛不是医学清除证明。视频用原机构公开播放器/来源链接，第三方不可用时保留完整文字说明，不转存他人视频或发布个人体态录像。

## 架构与数据
React + Vite，源码 training-app，编译到 rehab-training，兼容 index/app/pro/legacy-app.html。维持 GitHub Pages main 根目录部署，不自动发布本次分支。工作流改为只读校验构建，不再自动拼接旧脚本或回推。

设备本地版本化存储 move.personal.v1，无账号/云同步。首次成功建立新存储后仅移除已确认旧键 rehabPro.v4/v3/v2、rehabRecords、rehabGuideSeen、rehabWakeLockEnabled。新数据损坏不覆盖，提示先导出原数据再重置。保存失败保留输入、不显示成功、不关闭表单。导入验证版本、大小、字段、日期、动作标识和取值，防止原型污染；React仅作文本呈现。记录按训练开始时本地日期归档，跨午夜保持所属日。未来记录拒绝。多标签页更新采用写前版本检查，避免静默覆盖。

跟练只在明确完成一组时记账；计时结束不会自动算完成。暂停/恢复基于时间戳，页面重开保留训练位置且暂停。常亮只在活跃跟练请求，退出释放，重新可见时仅按用户偏好重试；失败或不支持如实显示，不保证后台/锁屏常亮。

## 验收
构建和领域测试；桌面1440×900、手机390×844及320px无横向溢出。实际点击今日→状态→跟练→逐组完成→结束→记录→刷新保留；主动休息、跳过、次日反馈、导入错误和存储拒绝；常亮成功/拒绝模拟；视频延迟加载；无加载框架异常。检查压缩资源、布局移动、长期任务、减少动画设置。其余页面 git diff 必须无变更。未在真实手机验证的系统常亮限制如实报告。
