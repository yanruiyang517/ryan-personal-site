# MOVE · 个人训练

浅色、移动端优先的个人跟练站。源码位于本目录，构建产物位于 `../rehab-training`。根目录简历和其他页面不属于此应用。

## 开发与构建

使用 Node.js 22.12 或更高版本。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

源码和构建产物一起提交。构建仅清理 `rehab-training`，生成 `index.html`，并复制为兼容旧链接的 `app.html`、`pro.html` 和 `legacy-app.html`。没有 Service Worker。GitHub Pages 仍按仓库既有设置读取 main 分支根目录；验证工作流只检查测试、构建和产物一致性，不自动提交或部署。

## 使用与数据

- 今日、每周计划、动作库、记录与设置均可独立访问；未来日期只预览。
- 计时依据时间戳计算，返回页面可校正经过时间；刷新后暂停。完成组数由用户确认，计时结束不会自动记为完成。
- 实际次数不足、跳过动作会记为部分完成。每天一份记录，重新开始时明确提示覆盖，并在最终保存前保留旧记录。
- 数据仅存于当前浏览器的 `move.personal.v1`，不会自动跨设备同步。支持 JSON 导入、导出；导入先校验再替换。
- 首次成功初始化后仅移除六个旧训练键：`rehabPro.v4`、`rehabPro.v3`、`rehabPro.v2`、`rehabRecords`、`rehabGuideSeen`、`rehabWakeLockEnabled`。没有调用 `localStorage.clear()`。
- 存储失败保留输入且不显示保存成功；多页面版本冲突要求刷新。损坏数据不自动覆盖，可先导出原始内容。
- 屏幕常亮依赖浏览器 Screen Wake Lock 支持和授权，需要 HTTPS 或 localhost。仅跟练中请求，离开跟练后释放；系统省电或切后台可能撤销。

## 内容与资源

动作说明包含剂量、步骤、常见错误和来源。官方视频点击后才加载；YouTube 网络不可达时可使用原始来源链接。Cornell 的向上够示范使用哑铃，页面明确提示初始阶段使用空手；步行提供官方活动指南，没有伪造动作示范。

阶段需要手动确认条件，不能仅凭日期自动升级。内容是保守的活动安排，不用于确诊或保证缓解疼痛。

室内氛围摄影是生成素材，仅作装饰，不是动作示范。图片压缩为 640px WebP；使用系统字体、Lucide 图标和轻量 CSS 过渡，尊重减少动态效果偏好。视频不会在首页预加载。

## 验证边界

Node 测试覆盖日期、计划、计时、真实完成量、迁移隔离、存储故障、并发版本和导入校验。页面交互在普通浏览器中人工验收。浏览器故障注入未执行，存储异常通过独立测试适配器验证；移动设备实际省电策略和视频地区可达性仍取决于设备与网络。
